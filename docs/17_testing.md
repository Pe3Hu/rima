# Шаг 17. Тестирование и критерии приёмки (Part / Stratum / Fulcrum)

**Цель.** Принять шаги 12–16.

**Зависит от.** Шаги 12–16.

## Ручные сценарии

### Сценарий 1. Поля `spine`/`bevel` в JSON
- В `tasks/<weapon>.json` добавлены поля `spine` и `bevel`.
- Загрузка не падает, если поля отсутствуют (пустые массивы).
- `PieceData.part` у клеток из `spine`/`bevel` соответствует ожидаемому.

### Сценарий 2. Переключение слоёв 1 / 2
- Нажатие «1» (или клавиша `1`) — виден Ingot-слой, Part-слой скрыт.
- Нажатие «2» (или клавиша `2`) — виден Part-слой (2 цвета), Ingot-слой скрыт.
- Переключение работает на всех трёх Mold.
- Piece-Label с толщиной виден в обоих режимах.

### Сценарий 3. Stratum (default)
- На оружии без флагов: одна группа Razor (справа налево) и одна группа Spike (сверху вниз).
- Fulcrum'ы Razor справа от правого края оружия, y = y соответствующих piece.
- Fulcrum'ы Spike сверху, x = x соответствующих piece.
- В stratum'е клетки идут контигуозно: разрыв по пустой клетке завершает stratum.

### Сценарий 4. Горизонтальная симметрия
- `is_horizontal_symmetric = true`: добавлены Razor-LEFT, Fulcrum'ы слева от левого края.
- Spike-TOP остался.

### Сценарий 5. Полная симметрия
- `is_fully_symmetric = true`: 4 направления Razor (RIGHT/LEFT/TOP/BOTTOM), Spike отсутствует.
- Fulcrum'ы: RIGHT/LEFT по горизонтали, TOP/BOTTOM по вертикали (визуально сверху/снизу, несмотря на подтип Razor).

### Сценарий 6. Сумма
- Число на Fulcrum равно сумме толщин piece'ов соответствующего stratum'а.
- После Fusion и пересборки Mold числа обновились.

### Сценарий 7. Клик
- ЛКМ по Fulcrum → подсветка Fulcrum + всех piece'ов stratum'а.
- Повторный клик → снять подсветку.
- Клик по другому Fulcrum → переключение.
- Клик вне Fulcrum → снять.

### Сценарий 8. Отсутствие регрессий
- Выбор Piece и A/D (шаги 9–10) работают.
- Fusion (шаг 10) работает.
- Слои 1/2 не влияют на выбор Piece и Fusion.

## Автоматические проверки (по возможности)
- `MoldTemplateData.get_part_at(coord)` возвращает `SPINE`/`BEVEL` для клеток из JSON и `NONE` вне них.
- `MoldData.strata` для default-конфига содержит ≥ 1 Razor-RIGHT и ≥ 1 Spike-TOP.
- При `is_horizontal_symmetric` есть хотя бы один Razor-LEFT.
- При `is_fully_symmetric` нет `SPIKE`, есть все 4 `direction`.
- `FulcrumData.sum == sum(piece.thickness for piece in FulcrumData.pieces)`.
