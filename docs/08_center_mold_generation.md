# Шаг 8. Генерация центральной Mold

**Цель.** Собрать центральную Mold из случайного решения `out/<weapon>.json`,
отличного от текущего левого решения, с вариантами Ingot'ов из Warehouse.

**Зависит от.** Шаг 7.

## Требования

- Метод `ForgeData.refill_center() -> void`.
- Алгоритм:
  1. Загрузить все решения для текущего оружия из `out/<weapon>.json`
     (через загрузчик солвера, `MaskBoardData` + DLX — уже есть).
  2. Исключить решения, совпадающие с текущим левым (по набору Ingot'ов,
     позиций, поворотов и flip; толщины не сравниваются, потому что
     у левого и правого они отличаются).
  3. Если после исключения список пуст — использовать все решения
     (защита от тупика).
  4. Выбрать случайное через `Helper.rng`.
  5. Для каждого Ingot'а в решении:
     - определить `shape` по форме;
     - выбрать случайный индекс варианта в Warehouse:
       `Helper.rng.randi_range(0, warehouse.get_variant_count(shape) - 1)`;
     - взять `IngotData` из Warehouse;
     - скопировать `origin`, `rotation_steps`, `is_flipped` из решения;
     - добавить в `center`.
  6. Заменить `center` на новую Mold с тем же шаблоном, эмитить
     `center_changed`, вызвать `recalc_right()`.
- `refill_center()` вызывается из `ForgeData.init_with_weapon()`
  автоматически.
- Ручной пересборки через кнопку в этом фронте работ **нет**. Если понадобится
  — отдельная задача в `notes.md` как «открытый вопрос».
- Инвариант: в `center` ровно 12 Ingot'ов, покрывающих все клетки шаблона
  без пересечений.

## Исключение «того же решения»

- Сравнение по нормализованному ключу: для каждого Ingot'а — `shape`,
  `origin`, `rotation_steps`, `is_flipped`; сортировка ключей, объединение
  в строку или в массив. Толщины в ключ не входят.
- Кэш решений — по оружию, чтобы не парсить JSON при каждом `refill_center`.
  Кэш — в `ForgeData`.

- [ ] Используется `Helper.rng`, никакого собственного RNG.
- [ ] Из решений исключается текущее левое.
- [ ] Если после исключения пусто — берётся любое.
- [ ] В `center` ровно 12 Ingot'ов, все клетки покрыты, пересечений нет.
- [ ] У Ingot'ов центра толщины из Warehouse (1..5), `origin`/`rotation`/

- [ ] При повторном вызове решение перегенерируется (с высокой вероятностью
      другое).
